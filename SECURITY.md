# Security Policy

## Reporting Security Issues

Do not publish passwords, credentials, API keys, private client information, assessment evidence, or other sensitive information in public GitHub issues.

When reporting a ClientGuard security issue, include:

- ClientGuard version
- Operating system
- Steps to reproduce
- Expected behavior
- Observed behavior
- Sanitized logs if appropriate

## Authorized Use

ClientGuard is intended for defensive cybersecurity assessments conducted with explicit authorization.
